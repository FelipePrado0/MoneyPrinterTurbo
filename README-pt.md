# MoneyPrinterTurbo 💸

### Um Gerador de Vídeos Curtos com IA, Tudo-em-Um

Informe um <b>tema</b> ou <b>palavra-chave</b> de vídeo, e o MoneyPrinterTurbo vai gerar o roteiro, buscar as imagens, criar legendas e trilha sonora, e produzir um vídeo curto em HD.

## Funcionalidades 🎯

### Fluxos de Criação

- [x] Use os fluxos de **AI Agent, WebUI, API ou CLI** para criação rápida ou produção automatizada
- [x] Vá de um tema até roteiro, narração, imagens, legendas, música e edição automaticamente, mantendo o controle sobre cada etapa
- [x] Gere múltiplas variantes de saída em lote, revise o histórico de tarefas, e importe ou exporte configurações de geração e chaves de API
- [x] Agende execuções de geração: rode uma vez ou repita diariamente/semanalmente/mensalmente, enfileire o mesmo tema múltiplas vezes ou vários temas diferentes, e deixe o dispatcher em segundo plano pegar e rodar cada ocorrência automaticamente
- [x] Proteja a WebUI com uma **trava de login**: configure um e-mail de conta, entre com uma senha fixa ou gerada automaticamente, e seja bloqueado automaticamente após tentativas repetidas de falha

### Roteiros e Provedores de Modelo

- [x] Gere ou reescreva **roteiros de vídeo multilíngues** com IA, ou forneça um roteiro customizado completo
- [x] Use provedores líderes incluindo [Kimi / Moonshot AI](https://platform.kimi.ai?track_id=track-f6b0a640d35c41deb03b247242a1058c&aff=moneyprinterturbo), [OpenAI](https://platform.openai.com/api-keys), [Anthropic Claude](https://platform.claude.com/settings/keys), [Google Gemini](https://aistudio.google.com/app/apikey), [DeepSeek](https://platform.deepseek.com/api_keys), [Alibaba Cloud Qwen](https://qwen.ai/apiplatform), [Microsoft Azure OpenAI](https://portal.azure.com/#view/Microsoft_Azure_ProjectOxford/CognitiveServicesHub/~/OpenAI), [ByteDance VolcEngine Ark](https://console.volcengine.com/ark), [xAI Grok](https://console.x.ai/), [MiniMax](https://platform.minimax.io/), e [Xiaomi MiMo](https://platform.xiaomimimo.com/docs/zh-CN/quick-start/first-api-call)
- [x] Conecte-se via [Shengsuan Cloud](https://www.shengsuanyun.com/?from=CH_XUQ4OTSK), [APIMart](https://go.apimart.ai/gh-moneyprinterturbo), [Cloudflare AI Gateway](https://dash.cloudflare.com/), [Alibaba ModelScope](https://modelscope.cn/docs/model-service/API-Inference/intro), [AIHubMix](https://aihubmix.com/), [AIML API](https://aimlapi.com/app/keys), [EvoLink](https://evolink.ai/dashboard/keys), [OpenRouter](https://openrouter.ai/settings/keys), [Ollama](https://ollama.com/), [assinatura Claude Code](https://code.claude.com/docs), [OneAPI](https://github.com/songquanpeng/one-api), [LiteLLM](https://docs.litellm.ai/docs/providers), [Groq](https://console.groq.com/keys), [Pollinations AI](https://enter.pollinations.ai/), e outros gateways ou runtimes locais compatíveis

### Imagens e Vídeos de Origem

- [x] Envie suas próprias **imagens e vídeos locais**, ou obtenha imagens de banco em HD do [Pexels (grátis)](https://www.pexels.com/api/), [Pixabay (grátis)](https://pixabay.com/api/docs/), e [Coverr](https://coverr.co/developers?ctx=header_navigation)
- [x] Gere imagens de origem em `768P` ou `2K` com o [Metaso MiniMax H3](https://metaso.cn/minimax-h3/?s=MPT), com clipes de 4 a 15 segundos em `9:16`, `16:9` ou `1:1`
- [x] Crie múltiplos clipes de vídeo com IA usando o [Shengsuan Cloud AI Video](https://www.shengsuanyun.com/?from=CH_XUQ4OTSK), depois combine-os com o fluxo de narração, legenda e edição do projeto
- [x] Use a integração nativa do [Volcano Engine Ark Seedance](https://console.volcengine.com/ark/region:ark+cn-beijing/apikey) para gerar imagens coesas a partir de segmentos individuais do roteiro
- [x] Transforme palavras-chave do roteiro em imagens de vídeo originais com o [WaveSpeed AI](https://wavespeed.ai)
- [x] Acesse Seedance, Wan e outros modelos de texto-para-vídeo através do [OFox](https://ofox.ai) com uma única chave de API
- [x] Conecte serviços de [texto-para-imagem compatíveis com OpenAI](https://platform.openai.com/docs/guides/image-generation) ou gateways de imagem customizados e transforme imagens geradas em clipes de vídeo animados
- [x] Ajuste a duração dos clipes, o modo de enquadramento e a ordem das imagens para se adequar a diferentes proporções e estilos narrativos
- [x] Envie um vídeo longo que já tenha uma trilha de voz e corte-o automaticamente em um clipe vertical (até 60 segundos), com legendas geradas por reconhecimento de fala local (STT) sobre o áudio original, terminando numa fronteira de frase — sem roteiro nem voz sintética envolvidos

### Narração, Legendas e Trilha Sonora

- [x] Escolha narração automática, áudio enviado, ou sem narração, com amostras de voz e prévias completas de narração
- [x] Use **Edge TTS (grátis, sem necessidade de chave de API)**, Azure Speech, SiliconFlow, Google Gemini, Xiaomi MiMo, MiniMax, ElevenLabs, Chatterbox, Kokoro, Fish Audio, e outros serviços de voz
- [x] Gere legendas e configure sua fonte, posição, cor, tamanho, contorno e estilo de fundo
- [x] Use trilha sonora aleatória, local, ou gerada por IA, com controle de volume independente

### Saída e Publicação

- [x] Exporte vídeos em retrato `9:16 (1080×1920)`, paisagem `16:9 (1920×1080)`, ou quadrado `1:1 (1080×1080)`
- [x] Publique vídeos concluídos diretamente no **TikTok, Instagram e YouTube Shorts**

## Requisitos do Sistema 📦

- Plataformas recomendadas: Windows 10+, macOS 11+, ou uma distribuição Linux mainstream
- A implantação local requer Python 3.11 ou superior; Python 3.11 é o recomendado
- GPU não é obrigatória, mas é recomendada se você quiser transcrição local mais rápida, processamento de vídeo mais rápido, ou geração em lote mais fluida

| Item | Mínimo         | Recomendado  | Ideal      |
| ---- | -------------- | ------------ | ---------- |
| CPU  | 4 núcleos      | 6 a 8 núcleos| 8+ núcleos |
| RAM  | 4 GB           | 8 GB         | 16+ GB     |
| GPU  | Não necessária | 4+ GB VRAM   | 8+ GB VRAM |

- Se você depende principalmente de LLMs na nuvem, TTS na nuvem e fontes de imagem online, CPU e RAM importam mais do que GPU
- Se você usa `faster-whisper`, geração em lote, ou processamento local mais pesado, uma GPU vai melhorar o throughput de forma perceptível

## Instalação e Implantação 📥

### Pré-requisitos

- A implantação local requer Python 3.11 ou superior
- No Windows, evite caminhos de projeto contendo caracteres não-ASCII, caracteres especiais, ou espaços

#### ① Clone o Projeto

```shell
git clone https://github.com/FelipePrado0/MoneyPrinterTurbo.git
```

#### ② Conclua a Configuração Inicial

No primeiro lançamento, o projeto cria o `config.toml` a partir do `config.example.toml`, então você não precisa criar o arquivo manualmente. Antes de usar LLMs na nuvem, imagens online, ou serviços de vídeo com IA, adicione as chaves de API correspondentes nas configurações básicas da WebUI.

### Implantação via Docker 🐳

#### ① Inicie o Container Docker

Se o Docker não estiver instalado, [baixe e instale o Docker Desktop](https://www.docker.com/products/docker-desktop/) primeiro.
Se você estiver usando um sistema Windows, consulte a documentação da Microsoft:

1. [Instalar o WSL](https://learn.microsoft.com/en-us/windows/wsl/install)
2. [Usar containers Docker com o WSL](https://learn.microsoft.com/en-us/windows/wsl/tutorials/wsl-containers)

```shell
cd MoneyPrinterTurbo
docker compose -f docker-compose.release.yml up
```

> O padrão recomendado é `docker-compose.release.yml`, que baixa a imagem pré-compilada do GitHub Container Registry: `ghcr.io/harry0703/moneyprinterturbo:latest`.
> Se você precisar compilar a imagem localmente, ainda pode rodar `docker compose up`.
> Antes do primeiro início, copie `config.example.toml` para `config.toml` para que ele possa ser montado nos containers.

#### ② Acesse a WebUI

Abra seu navegador e visite http://127.0.0.1:8501

#### ③ Acesse a Documentação da API

Abra seu navegador e visite http://127.0.0.1:8080/docs ou http://127.0.0.1:8080/redoc

> A API permite acesso via navegador same-origin por padrão. Defina a variável de ambiente `CORS_ALLOWED_ORIGINS` apenas quando um frontend de navegador separado precisar chamar a API diretamente de outra origem, por exemplo `http://localhost:3000,https://frontend.example.com`. CORS não afeta curl, Postman, n8n, ou outros clientes server-side.

### Implantação Manual 📦

#### ① Crie um Ambiente Virtual Python

Use o [uv](https://docs.astral.sh/uv/) para gerenciar o ambiente Python e as dependências. O projeto suporta Python 3.11 ou superior; o exemplo abaixo usa Python 3.11.

```shell
git clone https://github.com/FelipePrado0/MoneyPrinterTurbo.git
cd MoneyPrinterTurbo
uv python install 3.11
uv sync --frozen
```

Se você ainda não usa `uv`, também pode usar `venv + pip`.

```shell
python3.11 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Observações:

- `pyproject.toml` agora é o manifesto principal de dependências.
- `uv.lock` fixa o ambiente resolvido, então `uv sync --frozen` é o recomendado por padrão.
- `requirements.txt` é mantido apenas para instalação legada baseada em `pip`.

#### ② Inicie a WebUI 🌐

Note que você precisa executar os comandos abaixo no `diretório raiz` do projeto MoneyPrinterTurbo

###### Windows

```powershell
.\webui.bat
```

Você também pode rodar `webui.bat` no CMD.
`webui.bat` prioriza o `.venv` do projeto ou o Python empacotado do pacote portátil. Se nenhum Python do projeto for encontrado mas o `uv` estiver instalado, ele automaticamente recorre ao `uv run streamlit`.
Para permitir que outros dispositivos na sua LAN acessem a WebUI, rode `set MPT_WEBUI_HOST=0.0.0.0` antes de rodar `webui.bat`.

###### macOS ou Linux

```shell
sh webui.sh
```

O script usa automaticamente o ambiente virtual do projeto ou o `uv` e seleciona uma porta local disponível. Para permitir acesso de outros dispositivos na sua LAN, rode:

```shell
MPT_WEBUI_HOST=0.0.0.0 sh webui.sh
```

Após iniciar, o navegador vai abrir automaticamente

#### ③ Inicie o Serviço de API 🚀

```shell
uv run python main.py
```

Se você já ativou o ambiente virtual manualmente, ainda pode rodar:

```shell
python main.py
```

#### ④ Modo CLI Puro (Sem Navegador) ⌨️

Se você não consegue usar um navegador ou encaminhamento de porta, gere vídeos direto pela
linha de comando. O comando de geração completo mais simples é:

```shell
uv run python cli.py --video-subject "Como a IA está mudando o dia a dia"
```

O estilo de legenda e as opções de narração são resolvidos nesta ordem: **opção explícita da CLI >
valor `[ui]` salvo no `config.toml` > padrão embutido**. Outras configurações de geração,
como trilha sonora, quantidade de vídeos, e quantidade de parágrafos, não são herdadas
da WebUI. Se a WebUI estiver configurada para usar áudio enviado, passe `--custom-audio-file`
explicitamente, já que o caminho enviado não é persistido.

Para a referência completa de comandos, descrições de parâmetros, e instruções de uso,
rode:

```shell
uv run python cli.py --help
```

Para rodar várias tarefas sequencialmente, passe um array JSON em UTF-8 ou um manifesto JSONL. As
opções da CLI atuam como padrões, e cada objeto sobrescreve campos de `VideoParams`:

```json
[
  { "video_subject": "Como painéis solares funcionam" },
  { "video_subject": "Como turbinas eólicas funcionam", "video_aspect": "16:9" }
]
```

```shell
uv run python cli.py --batch-file ./tasks.json --stop-at video
```

O manifesto é resolvido a partir do diretório de trabalho atual. Valores relativos de
`custom_audio_file` e `video_materials[].url` locais dentro dele são resolvidos
a partir do diretório do manifesto; caminhos de arquivo fornecidos como padrões da CLI mantêm sua
semântica normal relativa ao diretório de trabalho atual. Um manifesto é limitado a 100 tarefas e 1 MiB.
Todas as entradas são validadas antes da primeira tarefa começar, as tarefas continuam após uma
falha de execução individual, e o comando imprime um resumo JSON único ao terminar.
O resumo contém `total`, `succeeded`, `failed`, e `tasks`; cada entrada de tarefa tem
`index`, `task_id`, `status`, `result`, `failed_stage`, e `error`.

## Narração, Legendas e Trilha Sonora 🎙️

### Síntese de Voz

O **Azure TTS V1** na WebUI é alimentado pelo **Edge TTS** e é gratuito para usar sem chave de API. O MoneyPrinterTurbo também suporta **Azure TTS V2**, **SiliconFlow TTS**, **Google Gemini TTS**, **Xiaomi MiMo TTS**, **ElevenLabs TTS**, **Chatterbox TTS** auto-hospedado, **Kokoro TTS** auto-hospedado, **Fish Audio TTS**, e um modo sem voz.

Selecione um provedor e uma voz na WebUI, depois siga as instruções na tela para quaisquer credenciais necessárias. O Edge TTS não requer chave de API; [Azure TTS V2](https://portal.azure.com/) e outros provedores na nuvem exigem credenciais de suas respectivas plataformas. Veja as vozes disponíveis do Edge TTS na [lista de vozes](./docs/voice-list.txt).

### Geração de Legendas

Dois modos de geração de legenda estão disponíveis:

- **edge**: Usa os timestamps do TTS, roda rápido sem GPU, e é o modo padrão.
- **whisper**: Usa transcrição local com `faster-whisper` quando uma linha do tempo de legenda mais precisa é necessária. O modelo é baixado no primeiro uso.

Defina `subtitle_provider` no `config.toml` para trocar de modo. O Whisper usa o modelo `large-v3` de aproximadamente 3 GB por padrão. Para usar o modelo `large-v3-turbo`, menor e mais rápido, com aproximadamente 1,6 GB:

```toml
[app]
subtitle_provider = "whisper"

[whisper]
model_size = "large-v3-turbo"
```

> No primeiro uso, o Whisper baixa automaticamente o modelo do Hugging Face. Se o download automático falhar, baixe o `whisper-large-v3` manualmente do [Hugging Face](https://huggingface.co/Systran/faster-whisper-large-v3).

Após extrair o modelo, coloque o diretório inteiro em `.\MoneyPrinterTurbo\models`. O caminho final deve ser `.\MoneyPrinterTurbo\models\whisper-large-v3`:

```
MoneyPrinterTurbo
  ├─models
  │   └─whisper-large-v3
  │          config.json
  │          model.bin
  │          preprocessor_config.json
  │          tokenizer.json
  │          vocabulary.json
```

### Trilha Sonora

A trilha sonora dos vídeos está localizada no diretório `resource/songs` do projeto.

> O projeto atual inclui algumas músicas padrão de vídeos do YouTube. Se houver problemas de direitos autorais, por favor
> apague-as.

### Fontes de Legenda

As fontes usadas para renderizar as legendas dos vídeos estão localizadas no diretório `resource/fonts` do projeto, e você também pode adicionar
suas próprias fontes.

## Perguntas Comuns 🤔

<details>
<summary>Como eu publico no YouTube?</summary>

Uploads para o YouTube passam pela API oficial YouTube Data API v3 (`google-api-python-client` + OAuth2), então o vídeo nunca passa por um serviço de terceiros.

Configuração única:

1. Crie um projeto no [Google Cloud Console](https://console.cloud.google.com/) e ative a **YouTube Data API v3**.
2. Configure a tela de consentimento OAuth, depois crie um cliente OAuth do tipo **Web application** e adicione `https://developers.google.com/oauthplayground` aos seus URIs de redirecionamento autorizados. O playground só aceita clientes web, então um cliente Desktop app não vai funcionar. Copie o Client ID e o Client Secret.
3. Obtenha um refresh token para o escopo `https://www.googleapis.com/auth/youtube.upload` no [OAuth Playground](https://developers.google.com/oauthplayground). Ative *Use your own OAuth credentials*, cole o client id/secret do passo 2, autorize o escopo com a conta do canal, depois troque o código pelos tokens.
4. Defina o status de publicação como **Production** na tela de consentimento. Enquanto o app permanecer em *Testing* com tipo de usuário externo, o Google revoga o refresh token sete dias após o consentimento.

Adicione o resultado em `[app]` no `config.toml`:

```toml
[app]
youtube_enabled = true
youtube_client_id = "seu-client-id"
youtube_client_secret = "seu-client-secret"
youtube_refresh_token = "seu-refresh-token"
youtube_auto_upload = true
youtube_privacy_status = "public"     # public, unlisted ou private
youtube_category_id = "22"            # 22 = People & Blogs
youtube_made_for_kids = false
youtube_contains_synthetic_media = true
```

Reinicie o app após salvar. Todo vídeo gerado é então enviado com um título, descrição e tags produzidos pela LLM. O refresh token se renova sozinho, então a publicação nunca abre um navegador — o que também faz funcionar no Docker e em servidores headless.

As mesmas configurações estão disponíveis na WebUI em **Settings → Auto-Publish Settings**.

Para notificar um sistema externo depois que um vídeo for publicado no YouTube (por exemplo, para disparar outra automação), adicione:

```toml
[app]
youtube_publish_webhook_url = "https://seu-endpoint.exemplo.com/webhook"
```

Toda publicação bem-sucedida envia uma requisição `POST` para essa URL com o ID do vídeo, link, título, descrição e tags. Uma notificação com falha apenas gera log e nunca afeta a publicação que já teve sucesso.

</details>

<details>
<summary>Como eu publico no TikTok ou Instagram?</summary>

Essas plataformas ainda passam pelo [Upload-Post](https://upload-post.com/). Crie uma conta e uma chave de API, depois adicione o seguinte em `[app]` no `config.toml`:

```toml
[app]
upload_post_enabled = true
upload_post_api_key = "sua-api-key"
upload_post_username = "seu-username"
upload_post_platforms = ["tiktok", "instagram"]
upload_post_auto_upload = true
```

As duas integrações são independentes e podem rodar ao mesmo tempo. Um `youtube` deixado em `upload_post_platforms` é ignorado, então o mesmo vídeo nunca é publicado duas vezes.

</details>

<details>
<summary>Como eu uso o provedor oficial Volcano Engine Ark Seedance?</summary>

Crie uma [chave de API Ark](https://console.volcengine.com/ark/region:ark+cn-beijing/apikey), depois configure o provedor em `[app]`:

```toml
[app]
volcengine_seedance_api_key = "sua-ark-api-key"
volcengine_seedance_model = "doubao-seedance-1-0-pro-250528"
volcengine_seedance_base_url = "https://ark.cn-beijing.volces.com/api/v3"
```

Quando o valor de configuração dedicado estiver vazio, `VOLCENGINE_ARK_API_KEY` é usado, seguido pela configuração LLM existente `volcengine_api_key`. Selecione **Volcano Engine Seedance** como fonte de vídeo e confirme explicitamente a geração paga antes de iniciar. Usuários de CLI precisam adicionar `--confirm-seedance-charge`.

A primeira integração suporta apenas texto-para-vídeo. Todo clipe enviado é uma tarefa Ark assíncrona paga; o app faz polling do mesmo task ID, para de enviar após um estado desconhecido, e baixa apenas clipes suficientes para cobrir a narração.

</details>

<details>
<summary>RuntimeError: No ffmpeg exe could be found</summary>

Normalmente, o ffmpeg é baixado e detectado automaticamente.
No entanto, se o seu ambiente tiver problemas que impeçam downloads automáticos, você pode encontrar o seguinte erro:

```
RuntimeError: No ffmpeg exe could be found.
Install ffmpeg on your system, or set the IMAGEIO_FFMPEG_EXE environment variable.
```

Nesse caso, baixe o FFmpeg de [gyan.dev](https://www.gyan.dev/ffmpeg/builds/), extraia-o, e defina `ffmpeg_path` para
o caminho real de instalação.

```toml
[app]
# Defina de acordo com seu caminho real, note que os separadores de caminho do Windows são \\
ffmpeg_path = "C:\\Users\\harry\\Downloads\\ffmpeg.exe"
```

</details>

<details>
<summary>OSError: [Errno 24] Too many open files</summary>

Esse problema é causado pelo limite do sistema no número de arquivos abertos. Você pode resolvê-lo alterando o limite de abertura de arquivos do sistema.

Verifique o limite atual:

```shell
ulimit -n
```

Se estiver muito baixo, você pode aumentá-lo, por exemplo:

```shell
ulimit -n 10240
```

</details>
